# 补齐提示框上下间距

PayTaxNZ 首页通过 Alert widget 输出迁移提示，其下方紧贴发票卡片。公共 `.alert` facade 缺少默认外边距，已补齐上下各 16px 的间距，并保留显式 spacing utility 的覆盖行为。

- 改动：`resources/modern/compat-facade.css` 的公共 alert 增加 `margin-block: 16px`；生产构建已更新 `resources/dist/` 的 hashed CSS、manifest、fallback 与固定资源 facade。
- 验证：官方 Chrome extension 使用与 `HomeController` 相同的独立 row/column 结构，在桌面和 375px 视口实测提示框上下 margin 为 16px、下方卡片间距由 0px 变为 16px；`mb-0` 的 margin-bottom 仍为 0px、关闭按钮位于框内、没有横向溢出。`npm run prod`、`npm run artifact`、`npm run bootstrap-absence`、`git diff --check` 通过。仅 CSS 改动，未运行 PHP/Laravel 或全量测试；当前无可用子代理，未声称独立审查。
- codestable：这是既有提示框布局的有界修复，不改变 View spec 的架构或接口；验证结果在本事项记录。
- 沉淀检查：无 Talk、Note、Tool 增量，未形成独立决策或新复用流程。
