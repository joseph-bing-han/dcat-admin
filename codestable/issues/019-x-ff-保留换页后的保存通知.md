# 保留换页后的保存通知

## 做了什么

已修复设置页保存成功返回设置页后的通知消失，保留10秒显示时间。实际消费AuthController显式关闭PJAX，容器selector为空，保存后整页刷新丢失内存通知；同时公共bridge局部unmount无条件overlayStore.reset也会导致PJAX场景立即清空。前轮仅延长时长未覆盖跳转生命周期。

## 改了哪些

`store.ts` 与 `bridge.tsx` 在局部卸载时保留可见/排队通知及原计时器，继续关闭页面dialog/drawer；全局卸载/stop仍完整清理。`runtime.ts` 对无PJAX的同站整页跳转使用sessionStorage暂存响应提示，新页面创建runtime后恢复一次并按默认时长计时，核对目标路径并拒绝超过60秒记录；不携带跨站提示。三个聚焦测试文件及发布JS同步。

## 怎么验证

store/bridge/runtime三文件59项测试、typecheck、生产build、artifact、git diff --check通过；覆盖PJAX提示可见和原计时、排队与dialog/drawer清理、全局stop、整页一次性恢复及无效记录丢弃。

Chrome extension隔离真实设置页仅替换最终编译JS响应，使用合成成功响应触发同站GET整页刷新，新文档5500.7ms时提示可见，暂存记录已消费，超过10秒后提示关闭。[刷新后的提示截图](../../artifacts/pjax-save-notice/after-refresh.jpg)及 `artifacts/pjax-save-notice/verification.json` 留证。未提交设置POST或修改账号，未部署消费应用；拦截规则清空、临时页关闭。既有 `$ is not defined` 初始化错误未在本次修复范围内，不宣称所有控制台错误已消除。
