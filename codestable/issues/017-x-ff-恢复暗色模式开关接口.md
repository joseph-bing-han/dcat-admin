# 恢复暗色模式开关接口

## 做了什么

已恢复仪表盘 DarkModeSwitcher 的初始化与当前页面主题切换。公共 Widget 输出 initSwitcher，但新版 NativeDcat 原先缺此接口；实际仪表盘复现 Dcat.darkMode 未定义错误。

## 改了哪些

`resources/modern/runtime.ts` 的 NativeDcat 从创建时提供 darkMode.initSwitcher，复用 init 生命周期并同步图标、aria-pressed、当前配置与键盘操作。回调使用 DOM this，兼容旧 init 包装的 jQuery 首参，避免重复事件绑定。`runtime.test.ts` 新增3项回归覆盖立即初始化、重复调用、新节点、既有暗色、键盘及compat包装；发布JS/facade已生产构建。未引入旧 renderer、主题依赖或跨刷新持久化，不改业务数据。

## 怎么验证

runtime 28项测试、typecheck、生产 build、artifact、git diff --check 通过。Chrome extension 隔离真实仪表盘标签页，资源请求阶段仅将现代JS响应替换为最终编译 `dcat-modern-CsxN5AUj.js`，原 CreateDcat 与 Widget inline 脚本按原顺序执行；相对旧错误基线无新增错误。鼠标切暗色、Enter切浅色、图标及aria-pressed同步通过；[暗色截图](../../artifacts/dark-mode-switcher/dark.jpg) / [浅色截图](../../artifacts/dark-mode-switcher/light.jpg)。拦截规则已清空、预览页已关闭，未部署或修改消费应用磁盘资源，未发起业务写入。
