# 修复区间列筛选单端渲染

## 做了什么

生产支出页仅传入 `filter-total[start]=41` 时，Between 渲染直接读取缺失的 end。已合并渲染默认边界，支持只填 start 或 end，保持既有单端查询语义；尚未部署生产。

## 改了哪些

修改 `src/Grid/Column/Filter/Between.php` 一行，并新增 `tests/Feature/ColumnBetweenFilterTest.php`；不更改共享 Filter 或前端资源。

## 怎么验证

修复前使用生产 URL 的参数复现 Between.php:191 缺失 end，上限单端复现缺失 start。修复后 `vendor/bin/phpunit --bootstrap vendor/autoload.php tests/Feature/ColumnBetweenFilterTest.php` 通过9项测试、21个断言，覆盖真实 Request 的单端、双端、无参数、空端及既有查询绑定。两个 PHP 文件语法检查及 `git diff --check` 通过。实际环境 PHP 8.1.34、Laravel 9.52.22；未运行浏览器及生产验证。无子代理接口，本会话自查未发现新增缺陷，未做独立审查。
